# 07_交付检查 / Delivery Checklists

## 1. 触发条件

任何涉及代码、页面、原型、文件、规则包、文档包、可复用模板的任务，都要启用本模块。

## 2. 页面不坏

检查：

- 页面能否正常加载。
- 是否出现空白页。
- 是否乱码。
- 布局是否明显错乱。
- 导航是否可用。
- 控制台是否有明显报错。

## 3. 功能可用

检查：

- 按钮是否能点击。
- 输入是否有效。
- 保存是否成功。
- 重置是否正常。
- 导出是否可用。
- 状态变化是否正确。
- 异常情况是否有反馈。

## 4. 链路走通

按真实用户路径完整测试：

1. 用户从哪里进入？
2. 用户第一眼能否理解？
3. 用户如何完成核心任务？
4. 用户在哪里可能卡住？
5. 完成后是否有明确反馈？

## 5. 文件包检查

如果交付的是文件包或规则包，检查：

- 目录是否存在。
- 入口文件是否存在。
- 被引用的模块是否存在。
- 文件名是否清晰。
- 中文文件名是否能正常打包。
- README 是否说明使用方式。
- 变更日志是否记录本次修改。
- 压缩包是否能正常解压。

## 6. 交付说明禁止只写“已测试”

必须具体说明测试过什么。例如：

> 我已检查压缩包结构、入口文件引用、模块文件数量、README 调用说明和变更日志记录。未运行真实 Codex 环境，建议你放入项目根目录后用一个简单任务验证调用效果。
