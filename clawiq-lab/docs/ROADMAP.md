# 产品路线图

## V0.1（本次）

- [x] Python 可复现合成出题，回答与答案隔离。
- [x] 可核验的独立计分、离线 HTML 报告、明确 DEMO 提示。
- [x] 可选 OpenClaw 一次性会话接入，无需额外 SaaS。
- [x] Skill 使用说明、隐私边界、自动化单元测试。
- [ ] 用户本地 OpenClaw 真实运行验收（不在本次环境执行）。

## V0.2（需基于用户反馈排序）

- [ ] 更多推理家族、题型均衡与再测试稳定性。
- [ ] 真实工具调用沙箱任务（文件操作、调用顺序等）以及程序验收；必须限制宿主文件系统权限。
- [ ] 独立模拟多会话记忆任务；清楚区分短期上下文与长期记忆。
- [ ] 训练前后配对实验：保留未训练过的验证题，检测负向回归；不得直接操作用户现有 Skill。

## 不做的事

- 不把趣味指数称作人类 IQ。
- 不拿用户隐私或真实消息当测试集。
- 不提供自动改配置、自动付费、自动上传日志或无证据的全球排行榜。
