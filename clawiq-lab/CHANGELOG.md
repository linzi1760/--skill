# 更新日志

## v0.1.1 — 2026-10-16

- 加入只读 `doctor` 兼容预检，在创建考试目录前检测 OpenClaw CLI 必要参数。
- 独立模式额外禁用全部模型工具与自动工作空间上下文注入，避免用户误以为检查了真实工具能力。
- 为 CLI 添加每题明确超时与清理宽限；返回记录明确出现工具调用时视为无效。
- 新增模拟 OpenClaw 可执行文件的进程级端到端回归，覆盖正常、工具调用异常和缺失 CLI。
- 保留已有 `clawiq-0.1` 题库与报告 schema，已生成的 V0.1 报告继续可复核。


## v0.1.0 — 2026-10-16

- 首次提供 12 题体验版与 40 题标准版动态合成题。
- 提供四维客观评分、脑力与模拟任务双分、趣味虾格类型以及 HTML 离线报告。
- 提供 Python CLI `generate/demo/run/score/verify/render`。
- 提供 OpenClaw 受限单次执行适配器和显式授权的真实 Gateway 测评适配器。
- 提供基础 Agent Skill、完整开发/方法学文档、安全边界、26个离线自动化测试。
- 暂无正式 OpenClaw 在线调用实测证据，不发布用户模型排行与训练效果结论。


## Unreleased — 2026-10-16

- 修复模块入口吞掉错误退出码，避免命令和 CI 失败时显示成功。
- 增加真实 Python 子进程的成功、缺失授权、缺失 CLI、输出保护、工具违规退出码测试。
- 复验发现固定 OpenClaw 2026.10.2 缺少当前隔离适配器要求的 `--config-override`；该兼容性阻塞必须单独解决，不能以旧绿色 CI 作为通过证明。

- 新增显式 --model/--provider-env 最小配置模式，兼容固定 CLI 的 --config，拒绝自动导入既有配置与凭据；原 override 路径保留。仅已验证 schema/CLI 与模拟进程，真实模型端到端待验证。
