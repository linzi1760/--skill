# V0.1 测评方法与有效性边界

## 测量对象

一次**具体执行配置**：模型 + OpenClaw CLI / 运行时 + 受限工具策略 + 一次性测试会话。不是人类智商、底层模型永久的能力或稳定人格。不同执行配置不可直接当成同一实体比较。

## 题库生成

`clawiq/core.py` 中按随机种子生成四类全合成题：

1. 逻辑推理：显式递推与多条件数量运算；有唯一数学答案。
2. 理解与遵循：模拟记录上的筛选、排序和 JSON 输出约束；代码计算答案。
3. 事实可靠性：支持、缺失、冲突三类模拟资料；按信息完整性客观判分。
4. 模拟任务：合成 `orders.json` 文本内容与有依赖的工作流；程序计算结果。

体验版 12 题，标准版 40 题。每题通过新随机数生成具体参数，答案独立保存在 `answer-key.private.json`。同 seed + 同版本重建出相同问卷。`commitment` 是 SHA-256 数据摘要，不是加密签名或在线考试作弊防护。

## 评分

所有题要求 `{"answer":...}` 的唯一 JSON 根对象，`answer` 类型严格比较（`true` 不等于 `1`）。格式错误算未通过。服务商错误、CLI 失败等使整次运行 `invalid`，不得发布数值总分。实时运行的未完成状态保留本地检查点，无最终有效报告。

四维分为本维正确数除以总题数 ×100，保留1位小数。

- 基础脑力：45% 推理 + 30% 指令 + 25% 可靠性。
- 模拟任务分：模拟任务正确率。
- 综合分：60% 基础脑力 + 40% 模拟任务。

这些权重是产品 V0.1 的**人为设计值**，不是数据驱动的心理测量校准。不得推断人类 IQ、全球分位或独立测量的创造力、安全性。

## 统计限制

- 体验版每维只有2–4题，受偶然性影响很大；标准版仍不足以当作科学量表。
- 一次性 first response，不检验采样方差和多次重复的一致性。
- 题型只有固定生成家族，可能存在对模板的记忆或规律捷径。动态 seed 不能完全消除训练集污染。
- 默认受限 `agent exec` 不能覆盖用户日常 Gateway 中已安装的完整工具与长期记忆。可选 `gateway` 会运行实际配置，但这不等于工具调用经过独立复核，也可能带来真实权限风险。
- 工作任务来自文字模拟资料，并**没有执行真实工具调用**，不能归因为某 Skill 生效或无效。
- 人格/虾格仅为视觉化称号，当前按相对最高维度决定，不宣称 AI 的心理状态。

## 后续验证门槛

1. 正式 OpenClaw 测试至少采集多个模型与运行时的成功、超时、结构化失败样本。
2. 增加两个独立题型家族后再讨论更强的泛化能力结论。
3. 不公开测试私有题目的答案；允许复核者在授权后访问证据。
4. 对照用户实际任务完成情况进行预测效度验证，并核查常见误判。
5. 在外部权限受控沙箱中验证工具调用与记忆后，才增加对应的正式计分维度。
